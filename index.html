AI 自习室

在 iPhone 或 iPad 上，把一份工作材料做成可以核对的成果。没有账号。记录留在这台设备。 On iPhone or iPad, turn one piece of work into a result you can check. No account. Records stay on the device.

  1. 1
    读材料Read the material

    从一堂大约十五分钟的课开始。课程原文是简体中文，用来对照固定事实。

    Start with a lesson of about fifteen minutes. Source text stays in Simplified Chinese so the facts can be checked.

  2. 2
    写下要求Write the request

    自己写给 AI 的提示。可以复制到你常用的工具，也可以在已配置的 HTTPS 服务里生成。发送前会先请你确认。

    Write the prompt yourself. Copy it into the tool you already use, or generate through a configured HTTPS service. Nothing is sent until you confirm.

  3. 3
    核对并留下Check it, then keep it

    把结果带回作品区，对照原文标出事实和仍待确认的地方。保存的成果带着提示、依据和验证范围。

    Bring the result back, mark what the source actually says, and keep what still needs confirmation. A saved result carries the prompt, the evidence, and the scope of the check.

第一课材料First lesson

1. 项目准备周四下午发布。 2. 小林负责文案初稿，周二 18:00 前提交。 3. 老周检查文案中的数据，下次会议之前完成。 4. 发布页面还需要校对，会上没有指定负责人。 5. 图片要用新品牌色，颜色值后续确认。

留在这台设备It stays on this device

没有账号No account
不注册，不同步，不投放广告，也不接入分析服务。
No sign-in, no sync, no ads, and no analytics.
iPhone 与 iPadiPhone and iPad
需要 iOS 18。窄屏是单列；宽屏把课程和练习并排。iPad 使用侧边栏，并支持分屏。
Requires iOS 18. Narrow screens stay in one column. Wide screens place the path beside the practice. iPad uses a sidebar and supports Split View.
备份由你保存Backups stay where you put them
可以导出 JSON 学习备份，并在另一台设备上合并缺失记录。文件去向由系统的文件选择器决定。
Export a JSON learning backup and merge missing records on another device. The system file picker decides where the file goes.
AI 自习室 0.2.0 界面提供 13 种语言。课程原文与自动验收保持简体中文。The interface ships in 13 languages. Lesson sources and automatic checks stay in Simplified Chinese.

AI 自习室

面向中文职场新手，练习核对 AI 输出里的负责人、时间和数字。找到原文依据，保留未确认项，对比修改前后，再换一份材料练习。无需账号，记录留在本机。 Practice checking AI outputs against Simplified Chinese workplace source material. Verify owners, times and numbers; keep unknowns, compare revisions and practice with another document. No account; records stay on-device.

一次具体的核对One concrete check

原文：「发布页面还需要校对，会上没有指定负责人。」
练习中故意写错：「负责人：小林」。
对照原文后修订为：「负责人：未确认」，并保留引用。预设错误是教学内容，不是假装成实时 AI 生成。

The source says a release page needs proofreading, without naming an owner. The exercise deliberately assigns Xiaolin. Correct the owner to “unconfirmed” and retain the quote. This is a labeled teaching exercise, not a live AI response.

行动表核对支持定位原文、查看修改前后、保存多份真实任务，并按已保存作品中出现的核对问题选择独立材料复练。检查只覆盖声明的规则，不保证整份作品正确。

Action-table checking includes source navigation, revision comparisons, multiple saved work products and practice based on observed checking issues. Checks cover the stated rules and do not certify an entire document.

  1. 1
    读材料Read the material

    第一步先读一句原文，找出行动表里没有依据的负责人。课程原文和核对问题说明保持简体中文。

    Start with one source sentence and find an unsupported owner in an action table. Source materials and authored checking explanations stay in Simplified Chinese.

  2. 2
    写下要求Write the request

    前几课先在 App 里写要求、对照原文。第 6 课才把虚构材料复制到你能打开的 AI 工具。当前 0.3.0 不提供课内实时模型服务，首课和本机核对可离线完成。

    Earlier lessons stay in the app: write the request and check it against the source. Lesson 6 is when you copy fictional material into an AI tool you can open. Version 0.3.0 does not include a live in-app model service. The first exercise and local checks work offline.

  3. 3
    核对并留下Check it, then keep it

    把结果带回作品区，对照原文修订事实和待确认项。保存的成果保留提示、依据与核对范围；教学示范不计学习通过，外部工具步骤属于学习者自报。

    Bring the result back and revise facts and open questions against the source. Saved work retains the prompt, evidence, and check scope. Teaching examples do not count as learning passes; external tool steps are self-reported.

第一课材料First lesson

1. 项目准备周四下午发布。 2. 小林负责文案初稿，周二 18:00 前提交。 3. 老周检查文案中的数据，下次会议之前完成。 4. 发布页面还需要校对，会上没有指定负责人。 5. 图片要用新品牌色，颜色值后续确认。

怎么读How to read it

周四下午是整场节点，不写成某一行行动的截止。校对没有指定负责人。颜色值还没给出，留成待确认。

Thursday afternoon is the event, not a deadline for one action. Proofreading has no named owner. The color value is not given, so it stays unconfirmed.

七课各练一件事Seven lessons, one skill each

  1. 行动表：节点不冒充行动，没写的人和时间留成待确认。Action table: a milestone is not an action, and unnamed people or times stay unconfirmed.
  2. 澄清邮件：只问会挡住跟进的空缺，每个问题附上原文。Clarification mail: ask only the gaps that block follow-up, and attach the source to each question.
  3. 需求表：被点名覆盖的用新值，讨论建议不升成已批准要求。Requirements: use the new value only where an override is named. A suggestion does not become an approved requirement.
  4. 方案比较：一条硬约束失败就不能推荐；两个都不满足就写无可行方案。Comparison: one failed hard constraint blocks a recommendation. If neither option works, write that none is feasible.
  5. 周报：完成数和计划数分开，材料里没有的增长率不补。Weekly report: keep finished counts apart from the plan, and do not add a growth rate the material never gives.
  6. 真实工具：自己运行，带回第一次结果，对照原文决定改还是留。A real tool: run it yourself, bring back the first result, and decide against the source whether to change it or keep it.
  7. 项目行动包：行动、比较、澄清和版本放在同一份里，不沿用上一课的选择。Project pack: actions, comparison, clarification, and version in one place, without carrying over the previous lesson’s choice.

留在这台设备It stays on this device

没有账号No account
不注册，不同步，不投放广告，也不接入分析服务。
No sign-in, no sync, no ads, and no analytics.
检查一份行动表Check an action table
先确认笔记里的人。时间分成任务截止和整场安排，再看表格有没有补造。真实任务与提供材料的练习分别保留草稿。核对练习记录不计整课完成；通过也不表示内容可以直接发出。
Confirm the people in the note. Split times into a task deadline and the event itself, then see whether the table added anything. Real work and supplied-material practice keep separate drafts. A check-practice record does not complete the full lesson, and a pass does not mean the result is ready to send.
iPhone 与 iPadiPhone and iPad
需要 iOS 18。窄屏是单列；宽屏把课程和练习并排。iPad 使用侧边栏，并支持分屏。
Requires iOS 18. Narrow screens stay in one column. Wide screens place the path beside the practice. iPad uses a sidebar and supports Split View.
备份由你保存Backups stay where you put them
可以导出 JSON 学习备份，并在另一台设备上合并缺失记录。备份包含真实任务与练习的核对草稿；恢复保留各类已有本机稿，只补空白草稿。文件去向由系统的文件选择器决定。
Export a JSON learning backup and merge missing records on another device. It includes check drafts for real work and practice. Restore keeps existing local content in each draft and fills only empty drafts. The system file picker decides where the file goes.

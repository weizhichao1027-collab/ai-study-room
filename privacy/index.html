本机记录On-device records

草稿、成果、提示、材料和帮助记录写在这台设备的应用支持目录里，文件名保持为既有的 state.json，以便已有记录仍能打开。工具名、实际步骤、首次输出与修订理由等自报记录也保存在本机。核对修订保留起始行动表、原文、核对次数及出现的问题类型，仅用于本机对比与复练建议。真实任务与练习的行动表核对草稿分别保留，写在同一目录的 grounded-session.json。这些文件使用“首次解锁前完成保护”的数据保护。应用不要求注册，也没有开发者账号同步。

Drafts, saved work, prompts, material, and help marks are written in this device’s application support folder. The file name stays state.json so existing records can still be opened. Self-reported tool names, steps, initial outputs, and revision reasons also stay on the device. Revision records retain the initial table, source, check count and observed issue types for on-device comparisons and practice suggestions. Real-work and practice check drafts are kept separately in grounded-session.json in the same folder. These files use complete data protection until the first unlock. The app does not ask you to register, and the developer does not sync an account.

不收集的内容What is not collected

应用不接入广告、分析、崩溃上报或第三方追踪 SDK。隐私清单声明不追踪、不收集数据。开发者不会因为你使用课程而收到你的材料、提示或成果。

The app does not include ads, analytics, crash reporting, or a third-party tracking SDK. Its privacy manifest declares no tracking and no collected data. The developer does not receive your material, prompts, or saved work because you used a lesson.

外部 AI 工具External AI tools

当前训练版本可以完全离线使用预先编写的课程示例。示例会明确标记，不会假装成实时模型，也不计为学习通过。外部工具的使用步骤由学习者填写，应用不观察你在外部工具中的操作。

The current practice build can be used offline with prepared lesson examples. They are explicitly labeled, are not presented as a live model, and do not count as learning passes. External tool steps are supplied by the learner; the app does not observe actions in external tools.

0.3.0 没有课内实时模型服务，不会把材料或提示发送给模型供应商。第 6 课由你主动复制虚构材料到自己选择的外部工具；进入该工具后的数据处理由其隐私政策说明。请勿复制敏感工作材料。

Version 0.3.0 has no live in-app model service and does not send material or prompts to a model provider. In lesson 6, you choose to copy fictional material into an external tool. Its privacy policy describes processing after you enter that tool. Do not copy sensitive work material.

备份、分享与复制Backup, share, and copy

导出学习备份会生成一个 JSON 文件，由你在系统文件面板里选择保存位置。真实任务和练习的核对草稿里已经写了内容时，这份文件会带上它们，也包含工具操作自报记录。导入只读取你选中的文件，并把缺失的学习记录合并进本机；同一条记录保留本机正文。恢复分别保留两类已有本机核对草稿，只补空白草稿；需要修复无法读取的原件时，先另存副本保留。恢复期间会在本机暂存原件快照和恢复标记，以便出错或进程中断时回滚。应用不会把备份上传到开发者。

Exporting a learning backup creates a JSON file, and you choose where the system file panel saves it. It includes nonempty real-work and practice check drafts, along with self-reported tool records. Import reads only the file you select and merges missing learning records onto this device. The same record keeps this device’s text. Restore keeps existing content in each check draft and fills only empty drafts. If an unreadable original needs recovery, it is retained in a separate copy first. During restore, original snapshots and a restore marker are temporarily kept on-device so errors or process interruptions can roll back. The app does not upload the backup to the developer.

分享成果使用系统分享面板，目的地由你选择。复制提示或材料时，文本只留在本机剪贴板，大约十分钟后过期，不会通过通用剪贴板同步到你的其他设备。

Sharing a result uses the system share sheet, and you choose the destination. When you copy a prompt or the material, the text stays on this device’s pasteboard, expires after about ten minutes, and is not synced to your other devices through Universal Clipboard.

语言Language

界面语言可以选择跟随系统，或在 13 种语言里指定一种。这个选择保存在本机偏好里。课程原文、教学示例和自动验收保持简体中文，因为核对依赖固定事实；翻译那份语料会让检查对上错误的证据。

The interface can follow the system, or you can choose one of 13 languages. That choice is stored in on-device preferences. Lesson sources, teaching examples, and automatic checks stay in Simplified Chinese because the check matches fixed facts. Translating that corpus would make the check accept or reject the wrong evidence.

删除Deletion

设置里可以删除全部本机学习资料，包括材料、草稿、成果、提示、学习记录和行动表检查草稿，以及应用为损坏文件留下的本地副本、恢复快照与标记、临时导出。已经分享到其他 App 或已保存到别处的备份不会被这次删除收回。删除单份草稿不会删除已经保存的成果。

Settings can delete all on-device learning data, including material, drafts, saved work, prompts, learning records, and the action-table check draft, plus retained copies of damaged files, restore snapshots and markers, and temporary exports. Files you already shared to another app, or backups you saved somewhere else, are not pulled back. Deleting one draft does not delete work you already saved.

儿童Children

应用不要求姓名、邮箱或账号。它不面向收集儿童个人信息。如果你认为一台设备上不该继续保留学习记录，请在设置中删除本机数据。

The app does not ask for a name, email address, or account. It is not designed to collect personal information from children. If a device should no longer keep learning records, delete the on-device data in Settings.

隐私政策Privacy policy

本机记录On-device records

草稿、成果、提示、材料和帮助记录写在这台设备的应用支持目录里，文件名保持为既有的 state.json，以便已有记录仍能打开。文件使用“首次解锁前完成保护”的数据保护。应用不要求注册，也没有开发者账号同步。

Drafts, saved work, prompts, material, and help marks are written in this device’s application support folder. The file name stays state.json so existing records can still be opened. The file uses complete data protection until the first unlock. The app does not ask you to register, and the developer does not sync an account.

不收集的内容What is not collected

应用不接入广告、分析、崩溃上报或第三方追踪 SDK。隐私清单声明不追踪、不收集数据。开发者不会因为你使用课程而收到你的材料、提示或成果。

The app does not include ads, analytics, crash reporting, or a third-party tracking SDK. Its privacy manifest declares no tracking and no collected data. The developer does not receive your material, prompts, or saved work because you used a lesson.

可选的 AI 服务Optional AI service

公开发行的训练版可以完全离线使用预先编写的课程示例。示例会标明“预先编写的课程示例”，不会假装成实时模型。

The published practice build can be used offline with prepared lesson examples. Those examples are labeled as prepared lesson examples and are not presented as a live model.

如果某个构建配置了你自己的 HTTPS 地址，提示页才会出现生成入口。只有在你点选确认之后，本次材料和提示才会 POST 到该地址。应用不保存模型供应商的密钥。请求会拒绝带有用户名或密码的地址，也不跟随重定向把内容再送出去。那个 HTTPS 服务由配置它的人运营，它收到内容之后如何处理，适用该服务自己的说明，不属于本应用的收集。

A build shows a generate action only when it was configured with your own HTTPS address. This material and prompt are posted there only after you confirm. The app does not store a model-provider key. It rejects addresses that contain a username or password, and it does not follow redirects in a way that resends the body. That HTTPS service is operated by whoever configured it. What happens after it receives the text is that service’s own notice, not collection by this app.

备份、分享与复制Backup, share, and copy

导出学习备份会生成一个 JSON 文件，由你在系统文件面板里选择保存位置。导入只读取你选中的文件，并把缺失记录合并进本机；同一条记录保留本机正文。应用不会把备份上传到开发者。

Exporting a learning backup creates a JSON file, and you choose where the system file panel saves it. Import reads only the file you select and merges missing records onto this device. The same record keeps this device’s text. The app does not upload the backup to the developer.

分享成果使用系统分享面板，目的地由你选择。复制提示或材料时，文本只留在本机剪贴板，大约十分钟后过期，不会通过通用剪贴板同步到你的其他设备。

Sharing a result uses the system share sheet, and you choose the destination. When you copy a prompt or the material, the text stays on this device’s pasteboard, expires after about ten minutes, and is not synced to your other devices through Universal Clipboard.

语言Language

界面语言可以选择跟随系统，或在 13 种语言里指定一种。这个选择保存在本机偏好里。课程原文、教学示例和自动验收保持简体中文，因为核对依赖固定事实；翻译那份语料会让检查对上错误的证据。

The interface can follow the system, or you can choose one of 13 languages. That choice is stored in on-device preferences. Lesson sources, teaching examples, and automatic checks stay in Simplified Chinese because the check matches fixed facts. Translating that corpus would make the check accept or reject the wrong evidence.

删除Deletion

设置里可以删除全部本机学习资料，包括材料、草稿、成果、提示和学习记录，以及应用为损坏文件留下的本地副本和临时导出。已经分享到其他 App 或已保存到别处的备份不会被这次删除收回。删除单份草稿不会删除已经保存的成果。

Settings can delete all on-device learning data, including material, drafts, saved work, prompts, and learning records, plus local copies the app kept for a damaged file and temporary exports. Files you already shared to another app, or backups you saved somewhere else, are not pulled back. Deleting one draft does not delete work you already saved.

儿童Children

应用不要求姓名、邮箱或账号。它不面向收集儿童个人信息。如果你认为一台设备上不该继续保留学习记录，请在设置中删除本机数据。

The app does not ask for a name, email address, or account. It is not designed to collect personal information from children. If a device should no longer keep learning records, delete the on-device data in Settings.

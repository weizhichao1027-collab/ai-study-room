技术支持Support

下面是应用里实际会遇到的操作。版本 0.3.0，需要 iOS 18，用于 iPhone 与 iPad。 These are the operations the app actually has. Version 0.3.0 requires iOS 18 and runs on iPhone and iPad.

继续上次的练习Continue the last practice

今天页的主按钮会打开尚未完成的草稿。全部尝试在“我的草稿”里。左滑可以删除一份草稿；已经保存的成果仍保留自己的副本。

The main button on Today opens the unfinished draft. Every attempt is listed in My drafts. Swipe to delete one draft. Saved work keeps its own copy.

从新手指引到自己的成果From the beginner guide to your own work

目前开放七课，每课只练一件事：行动和缺项分开、只问必要问题、分清覆盖与建议、按硬约束取舍、不把计划写成成果、在真实工具里带回并核对、再合成一份项目行动包。新手指引说明如何运行提示、导回结果、找错并修订。工具实操会保留工具名、实际步骤、第一次结果和修订理由；这些步骤是学习者自报，没有外部观察，也不构成 AI 能力认证。

Seven lessons are available, each teaching one skill: separate actions from gaps, ask only necessary questions, tell overrides from suggestions, choose by hard constraints, keep plans from being reported as results, bring a real tool’s output back and check it, then combine these into a project pack. The beginner guide explains how to run a prompt, bring back the result, find errors, and revise. Tool practice retains the tool name, steps, first output, and revision reason. Those steps are self-reported, without external observation, and do not certify AI ability.

教学示范用于参考，不能保存为学习通过。从示范开始自己的结果时，应用保留示范旧稿并建立空白指导尝试，继续记录已使用帮助。新材料用尽时会明确提示，你可以复习已用材料；复习不算对新材料的独立迁移证明。

Teaching examples are references and cannot be saved as learning passes. Starting your own result keeps the example draft and creates an empty guided attempt with its help history. When new material runs out, the app says so and offers review. Reviewing a seen task is not evidence of independent transfer to new material.

检查一份行动表Check an action table

今天页可以打开这项检查。先确认笔记里的人。时间分成任务截止和整场安排，再看表格有没有补造或漏项。补上的词必须在笔记里连续出现。真实任务和提供材料的练习各有草稿，切换时保留原内容。系统自动修复或具体教学帮助会记录为使用帮助。核对练习可以留记录，但不计为整课完成。界面换成其他语言时，页面会说明课程原文、教学示例和自动验收仍用简体中文。检查卡片里的依据句也保持简体，以便对照原文。

Today can open this check. Confirm the people in the note. Split times into a task deadline and the event itself, then see whether the table invented or omitted anything. An added phrase has to appear as a continuous span in the note. Real work and supplied-material practice keep separate drafts and preserve their content when you switch. Automatic repairs and concrete teaching help are recorded as assistance. A check-practice record does not complete the full lesson. When the interface is another language, the page says that lesson sources, examples, and automatic checks stay in Simplified Chinese. Evidence sentences on the check cards stay in Simplified Chinese so they can be matched to the source.

换语言Change the language

设置里可以选择跟随系统，或指定 13 种语言之一。切换后界面立即更新，包括阿拉伯语从右到左的排版。主屏幕上的应用名称跟随设备语言。课程原文、教学示例和自动验收仍是简体中文。

In Settings, follow the system or pick one of 13 languages. The interface updates immediately, including right-to-left layout for Arabic. The Home Screen name follows the device language. Lesson sources, examples, and automatic checks remain Simplified Chinese.

iPhone 与 iPadiPhone and iPad

iPhone 使用底部标签。iPad 和较宽的窗口使用侧边栏，学习路线和成果会分成两列。分屏或台前调度把窗口变窄时，界面回到单列。外接键盘可以用 ⌘1、⌘2、⌘3 切换今天、学习路线和我的成果。支持竖屏与横屏，也支持系统的更大文字和深色外观。

iPhone uses the bottom tabs. iPad and wider windows use a sidebar, and the path and saved work split into two columns. When Split View or Stage Manager makes the window narrow, the layout returns to one column. With a hardware keyboard, ⌘1, ⌘2, and ⌘3 switch Today, Path, and My work. Portrait, landscape, larger text, and Dark Mode are supported.

备份与恢复Backup and restore

在设置中导出学习备份，系统会让你选择保存位置。文件名以当前语言的应用名开头。备份包含真实任务和练习里已经写了内容的核对草稿，以及工具操作自报记录。恢复时先预览内容，再合并。同一条记录保留这台设备上的正文；帮助和示例标记只会增加，不会被备份清掉。恢复分别保留已有真实任务和练习稿，只补其中空白的草稿。没有核对草稿字段的旧备份仍然可以恢复学习记录。备份文件上限为 10 MB；过大、损坏或版本不符的文件不会覆盖现有记录。恢复未完整提交时会回滚；若仍无法恢复，先保留原件，暂不写入新草稿。

Export a learning backup from Settings and choose where the system saves it. The file name starts with the app name in the current language. It includes nonempty check drafts for real work and practice, plus self-reported tool records. Restore shows a preview, then merges. The same record keeps the text already on this device. Help and example marks can only be added, not cleared by a backup. Restore keeps existing real-work and practice drafts separately and fills only empty drafts. Older backups without check-draft fields can still restore learning records. The backup file limit is 10 MB; oversized, damaged, or unsupported files do not replace existing records. An incomplete restore rolls back. If recovery remains unavailable, original copies are retained and new draft writes are blocked.

核对没有通过The check did not pass

课程验收只覆盖附带的练习材料，并按简体中文里的固定事实核对。明确错误需要修订；规则无法识别的表达会提示尚未确认，你可以引用实际原文、解释判断并保存自报复核记录，这不计课程完成或独立通过。独立练习不提供参考答案；普通诊断反馈本身不记录帮助，使用具体教学提示或答案才会记录。自己的会议笔记可以转到行动表核对，但其有限检查也不构成完整课程验收。

Course checks cover the supplied practice materials and fixed facts in Simplified Chinese. Known errors need revision. Unrecognized wording is marked unconfirmed; you can quote the actual source, explain your judgment, and save a self-reported review record. It does not complete a lesson or count as an independent pass. Independent practice has no reference answer. Ordinary diagnostic feedback does not itself record help; concrete teaching hints or answers do. Your own meeting note can use the action-table check, whose limited result does not complete the full course.

导入导出与无法读取的草稿Import, export, and unreadable drafts

行动表可以导入应用导出的 13 种语言 CSV 表头或完整 Markdown 成果，后面的提示与材料不会被当作额外行动。CSV 为以公式触发字符开头的内容加上安全前缀，导回时保留该前缀。无法读取或超出限制的核对草稿不会被空白内容覆盖；页面可以先保留原件副本，再新建草稿。备份恢复尚未完成时，请先完成恢复，或在设置明确删除全部本机数据。

Action tables can import the app’s CSV headers in all 13 interface languages or a complete Markdown export. Later prompts and material are not imported as extra actions. CSV adds a safety prefix to cells that start with formula triggers, and import retains that prefix. Unreadable or oversized check drafts are not overwritten with blanks. The check page can retain an original copy before starting a draft. If a backup restore is still pending, complete recovery first or explicitly delete all on-device data in Settings.

需要联网或 AI 账号吗？Do I need a connection or AI account?

0.3.0 的首课、固定材料练习、行动表核对和本机保存均可离线使用，无需注册。此版本没有课内实时模型服务。第 6 课需要你在可访问的 AI 网站或工具中使用课程提供的虚构材料，再把结果带回来；外部工具可能需要自己的账号或网络。应用不能观察或核验你在其他工具里的实际操作。

The first exercise, fixed practice, action-table checking and local storage in 0.3.0 work offline without registration. This release has no live in-app model service. Lesson 6 asks you to use fictional course material in an accessible AI website or tool, then bring back the result. That tool may require its own account or connection. The app cannot observe or verify actions in other tools.

依据、修订和复练Evidence, revisions and practice

点击「定位原文依据」可在完整材料里查看引用；没有逐字匹配时会明确提示。行动表首次检查保留当时内容，后续修改可在「核对修订」里比较，随成果和备份保存；更换原文后重新开始对比。重新导入的行按新增和移除显示，不猜测对应关系。「我的成果」按作品统计曾出现的核对问题，同一作品反复检查不增加次数，练习预设错误不计入统计。你可以继续保存新的真实任务。

“Locate source evidence” shows a quote in the complete material or states that no exact match was found. The first action-table check retains a baseline for later revision comparisons, saved with your work and backups. Changing the source resets it. Reimported rows appear as additions/removals, without guessed matches. Saved work groups observed checking issues once per work product; repeated checks and planted course errors do not inflate counts. You can save further real-work documents.

删除本机数据Delete on-device data

设置底部可以删除全部本机学习资料，包括行动表检查草稿。正在生成时不能删除。已经分享出去或另存的文件不会消失。

The bottom of Settings can delete all on-device learning data, including the action-table check draft. Deletion waits until generation has finished. Files you already shared or saved elsewhere remain.

联系Contact

应用没有客服账号。请在 GitHub Issues 里描述机型、系统版本和你看到的原句。不要在 Issue 里粘贴客户材料、姓名或尚未公开的工作内容。

The app has no support account. Open a GitHub Issue with the device, the system version, and the exact sentence you saw. Do not paste client material, names, or unpublished work into an Issue.
